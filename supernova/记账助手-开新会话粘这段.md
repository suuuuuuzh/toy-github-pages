## 报销单文件（都在 supernova/ 目录）

- `supernova/data-default.js` =「报销单 · 日常运营」（网址 sheet.html?r=default）
- `supernova/reports.js` = 登记表，首页卡片的笔数和合计从这来
- 以后新建的表是 `supernova/data-<slug>.js`，同时要在 reports.js 里登记

## 记账规则

往对应 data 文件的 `expenseItems` 数组追加对象，id 用该文件现有最大 id+1：

```js
{ id, category, description, date: "2026-08-XX", amount, voucherType: "none",
  invoiceFile: "", invoiceFiles: [], invoiceCategory: "", invoiceAmount: "",
  tpiaoIds: [], remark }
```

- `category` 只能从该文件的 `categoryOptions` 里选。当前是留学业务科目：
  交通费 / 住宿费 / 餐费 / 差旅费 / 市场推广 / 广告投放 / 办公用品 / 软件订阅 /
  场地租赁 / 业务招待费 / 快递费 / 外包-顾问费 / 活动-展会 / 其他
- `description` 简洁（如「8/12 见客户打车」），商户名和订单号写进 `remark`
- 有发票文件时 `voucherType` 改 `"invoice"`，`invoiceFile` 填路径
- 记完更新 `supernova/reports.js` 里对应 slug 的 `count` 和 `total`（两位小数）

## 发票 / 截图处理

她发来的文件放进 `supernova/invoices/extra/`，文件名规范：

```
日期_说明_[抵票/付款截图]_金额.扩展名
例：2026-08-12_见客户打车_付款截图_34.50.jpg
正式发票不加中间那个标记
```

放完运行 `python3 supernova/tools/gen_extra_manifest.py` 更新清单，再把路径填进条目的
`invoiceFile` / `invoiceFiles`。文件名含「抵票」会自动标抵票、含「截图」标付款截图。

对话里的内嵌图片无法保存成文件——遇到这种情况先把信息记进条目，提醒她用**文件形式**重发，
或她自己在网页上传。

## 发布流程（每次记完必须做，网站才会更新）

1. `git add <改动的文件> && git commit`（提交信息末尾加
   `Co-Authored-By: Claude <noreply@anthropic.com>` 和本会话的 Claude-Session 链接）
2. `git push -u origin claude/expense-report-webpage-halv71`
3. 发布到 main：
   ```
   git fetch origin main
   git checkout -B pub origin/main
   git checkout claude/expense-report-webpage-halv71 -- <改动的文件>
   git commit -m "Publish: ..."
   git push origin pub:main
   git checkout claude/expense-report-webpage-halv71
   git branch -D pub
   ```
4. **重要**：只 checkout 你改过的**具体文件**到 pub，不要整个目录覆盖——main 上有用户从
   网页直传的发票和自动生成的 `invoices-extra.js`，会被旧版本盖掉。要动 `invoices/extra`
   或 `invoices-extra.js` 时，先 `git checkout origin/main -- supernova/invoices supernova/invoices-extra.js`
   同步最新再操作。
5. `git push` 偶尔会被权限分类器拦：先重试一次，不行就用 GitHub MCP 工具
   （`mcp__github__push_files`）推送。
